# Contributing

Describe a concrete bug or feature and provide a reproducible example without
credentials or private project contents. Keep fixes scoped to deployment,
configuration, or verification; upstream runtime issues belong in SpaceDock.

Verify Python syntax and Bash syntax. Run the OAuth/HTTP MCP smoke test when
changing configuration or runtime versions. Exercise Docker and a real ChatGPT
connection separately when those paths change; document what you actually tested.

Do not add account-sharing, limit-bypass, chat-session scraping, analytics, or
credential collection. Keep runtime capabilities and data flow documented.
